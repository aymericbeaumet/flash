# Code of conduct

Flash's issues, pull requests and discussions are for building a better tool
together. Be kind and assume good faith: critique code and ideas, never
people. Harassment, personal attacks, and discriminatory or sexual remarks are
not welcome in any space of this project.

The maintainer may edit or remove comments, lock threads and block accounts
that break these rules. To report a problem privately, contact
[@aymericbeaumet](https://github.com/aymericbeaumet) on GitHub; reports are
kept confidential.

This page follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
