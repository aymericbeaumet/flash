# mousemaster-shaped configuration

[`flash.toml`](flash.toml) follows mousemaster's neo-mousekeys layout: `alt+e`
enters NORMAL, `i` opens pointer mode, and `f`, `g`, `c` and `p` open hints,
the bisect grid, the display labels and the saved positions. See
[Coming from mousemaster](../../mousemaster.md) for the mode-by-mode table.
