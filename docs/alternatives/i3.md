# Flash and i3

[i3](https://i3wm.org) is "a tiling window manager, completely written from
scratch", "primarily targeted at advanced users and developers": a tree of
containers split, stacked or tabbed, binding modes, workspaces per output,
`for_window` and `assign` rules on window criteria, a scratchpad, and a JSON
IPC that `i3-msg` and every bar speak. It is BSD-3-Clause C for X11 on Linux
and the BSDs, about 10,600 stars, 4.25.1 in February 2026, with commits in
October 2026. It does not run on macOS. There, [AeroSpace](aerospace.md) is
the dedicated i3-like tiler; Flash's opt-in [tiling](../tiling.md) follows
the same tree, emulates workspaces the same way, and brings i3's binding
modes over as [layers](../layers.md).

| | i3 | Flash |
| --- | --- | --- |
| License, price | BSD-3-Clause, free | MIT, free |
| Platforms | X11 on Linux and the BSDs | macOS 13+ |
| Layouts | `splith`, `splitv`, `stacking`, `tabbed`, nested at will; floating | Opt-in tree: tiles or accordion, horizontal or vertical; floating |
| Workspaces | Real workspaces, assignable to outputs | Emulated: a hidden workspace's windows wait off a bottom corner of their display |
| Keys | `bindsym`, `bindcode`, binding modes | `[mode.all.mappings]` chords, NORMAL keys and sequences, layers, per-app tables |
| Rules | `for_window`, `assign`; criteria on class, instance, title, role, urgency | `[[tiling.rules]]` by bundle ID and title: float, or a workspace |
| Bar, IPC | i3bar with i3status or i3blocks; IPC with `get_tree` and `subscribe` | Built-in bar with `#{flash.workspaces}`; the `flash` CLI over a versioned socket ([IPC protocol](../ipc-protocol.md)), `workspace list`, `flash events watch`, events for monitors and plugins |
| Configuration | Text file, `reload` and `restart`, `i3 -C` checks it | TOML, live reload on save, `flash config check` |
| Maintenance | 4.25.1, February 2026; active | 1.1.0, October 2026; tiling is new |

## Where i3 is stronger

- **It is the window manager.** i3 owns every window from the moment it
  maps: it draws the title bars of tabbed and stacked containers, the
  borders and the urgency hints, and focus can follow the mouse. macOS lets
  no app replace WindowServer, so Flash, like AeroSpace, moves other apps'
  windows through Accessibility after they appear, and an app with a
  minimum size or a cell grid keeps its own frame ([limits](../tiling.md#limits)).
- **A richer tree.** `split h` and `split v` decide where the next window
  goes, `focus parent` and `focus child` walk the containers, marks name any
  container, and `append_layout` restores a saved layout. Flash inserts after
  the focused window, builds containers with `tile join`, has no parent
  focus, and forgets its trees when it restarts.
- **Real workspaces.** Switching is instant and nothing is left on screen.
  macOS gives no public API to switch Spaces, so Flash parks a hidden
  workspace's windows off a bottom corner, where Mission Control still shows
  them small.
- **A scratchpad for any window.** `move scratchpad` takes a browser or a
  chat window; Flash's nearest equivalent, a persistent popup, runs a
  terminal program only.
- **The IPC.** `get_tree`, `get_workspaces`, and `subscribe` to window,
  workspace, mode and binding events, with client libraries in many
  languages. Flash has `workspace list` and events, and no tree as JSON
  ([not yet](../tiling.md#not-yet)).

## Where Flash is stronger

- **Keys beyond windows.** i3's bindings move windows and `exec` programs.
  Flash's NORMAL mode adds hints on every button and link, Vim keys for tabs
  and scrolling in every app, and tables per app by bundle ID, which i3
  bindings never had.
- **Layers that take counts and sequences.** `3l` in a resize layer runs
  `l` three times, and a layer can hold `gg`-style sequences; Escape returns
  to the mode it was entered from.
- **Hooks without a subscriber script.** Where i3 needs a process holding an
  IPC `subscribe`, a [monitor](../monitors.md#runs-and-events) runs a
  command on `core:workspace.changed`, `core:focus.changed` or
  `core:displays.changed`, declared in the same file. A script that wants
  the stream itself reads `flash events watch` (NDJSON, `--name=<glob,...>`).
- **A bar that reads your i3blocks scripts unchanged** (`output =
  "i3blocks"`), with hover popups for btop or a calendar under a label.

## Flash features you might like

- `window switch` (`:ls`) lists every window with a hint label, what an
  i3 user does with `[title="…"] focus` without writing the criteria;
  `@windows` in the flashlight searches the titles.
- `mark set --letter=a` and `mark jump --letter=a` keep i3's marks habit
  for apps rather than containers.
- `#{flash.workspace}` and `#{flash.workspaces}` in the
  [bar](../tiling.md#the-bar-and-plugins), with no IPC client.
- `mouse target` labels whatever a window shows, for the clicks i3 never
  covered.

## Moving from i3

Super is Command on a Mac, and most Command chords belong to apps (Cmd-H
hides, Cmd-Q quits), so the snippets use Option, as AeroSpace does. A chord
in `[mode.all.mappings]` is taken system-wide: Option-letter no longer types
its accented character in any app.

| i3 | Flash, `[tiling] enabled = true` |
| --- | --- |
| `bindsym $mod+j focus left` | `"alt+j" = ["flash", "window", "focus", "--direction=left"]` |
| `move left` | `tile move --direction=left` |
| `split h`, `split v` | No split ahead of a window: `tile join --direction=` groups two, `tile layout --type=vertical` turns a container |
| `layout stacking`, `layout tabbed` | `tile layout --type=accordion`, without title bars |
| `floating toggle`, `fullscreen toggle` | `tile float`, `tile fullscreen` (`window fullscreen` for native full screen) |
| `resize grow width 10 px or 10 ppt` | `tile resize --dimension=width --amount=10`, in points |
| `kill` | `window close` |
| `workspace number 1`, `move container to workspace number 1` | `workspace switch --name=1`, `workspace move_window --name=1` |
| `workspace back_and_forth` | `workspace back_and_forth` |
| `workspace 1 output HDMI-1`, `move workspace to output right` | `[tiling.monitors]`, `workspace move_to_monitor --direction=next` |
| `for_window [class="XTerm"] floating enable`, `assign [class="^URxvt$"] → 2` | `[[tiling.rules]]` with `float = true` or `workspace = "2"` |
| `gaps inner 5px` | `[tiling.gaps] inner = 5` |
| `mode "resize" { … }` | A [layer](../layers.md) |
| `move scratchpad`, `scratchpad show` | A `persistent = true` terminal [popup](../popups.md), shown by `mode terminal --name=` |
| `exec_always ~/my_script.sh` | A monitor on `core:config.changed`, which fires at launch and on every save |
| `i3-msg -t get_workspaces`, `i3-msg -t subscribe '["workspace"]'` | `flash workspace list`, a monitor on `core:workspace.changed` |
| `bar { status_command i3status }` | `[statusbar]`; see [i3status](i3status.md) and [i3blocks](i3blocks.md) |
| `xprop` for a window's class | `flash resident status --json`: `focused_app` is the bundle ID rules match |

The everyday keys, without any mode:

```toml
[tiling]
enabled = true
workspaces = ["1", "2", "3"]

[tiling.gaps]
inner = 5
outer = 5

[tiling.monitors]
"3" = "secondary"

[[tiling.rules]]
bundle_id = "com.apple.systempreferences"
float = true

[[tiling.rules]]
bundle_id = "com.tinyspeck.slackmacgap"
workspace = "3"

[mode.all.mappings]
"alt+h" = ["flash", "window", "focus", "--direction=left"]
"alt+j" = ["flash", "window", "focus", "--direction=down"]
"alt+k" = ["flash", "window", "focus", "--direction=up"]
"alt+l" = ["flash", "window", "focus", "--direction=right"]
"alt+shift+h" = ["flash", "tile", "move", "--direction=left"]
"alt+shift+j" = ["flash", "tile", "move", "--direction=down"]
"alt+shift+k" = ["flash", "tile", "move", "--direction=up"]
"alt+shift+l" = ["flash", "tile", "move", "--direction=right"]
"alt+w" = ["flash", "tile", "layout", "--type=accordion"]
"alt+shift+f" = ["flash", "tile", "fullscreen"]
"alt+shift+<space>" = ["flash", "tile", "float"]
"alt+shift+q" = ["flash", "window", "close"]
"alt+1" = ["flash", "workspace", "switch", "--name=1"]
"alt+2" = ["flash", "workspace", "switch", "--name=2"]
"alt+3" = ["flash", "workspace", "switch", "--name=3"]
"alt+shift+1" = ["flash", "workspace", "move_window", "--name=1"]
"alt+shift+2" = ["flash", "workspace", "move_window", "--name=2"]
"alt+shift+3" = ["flash", "workspace", "move_window", "--name=3"]
"alt+<tab>" = ["flash", "workspace", "back_and_forth"]
"alt+<return>" = ["flash", "app", "open", "--name=Terminal"]
"alt+d" = ["flash", "mode", "flashlight"]
"alt+<minus>" = ["flash", "mode", "terminal", "--name=scratchpad"]

[popup.scratchpad]
command = ["$SHELL", "-l"]
size = "60%x50%"
persistent = true

[statusbar]
enabled = true
template = "#[align=left]#[pill] #{flash.workspace} #[nopill] #{flash.workspaces}#[align=right]%a %d %b %H:%M"
```

The resize mode is a layer. A layer needs Flash's modes, which an all-mode
chord bound to `mode normal` or `mode leave` turns on; Flash then starts in
NORMAL, where unmapped letters are swallowed until `i` hands typing back
([advanced mode](../modes.md#advanced-mode)). Escape leaves the
layer, as `mode "default"` does in i3:

```toml
[mode.all.mappings]
"cmd+ctrl+[" = ["flash", "mode", "normal"]
"cmd+ctrl+i" = ["flash", "mode", "insert"]
"alt+r" = ["flash", "mode", "layer", "--name=resize"]

[mode.layers.resize]
label = "RESIZE"

[mode.layers.resize.mappings]
"h" = ["flash", "tile", "resize", "--dimension=width", "--amount=-10"]
"l" = ["flash", "tile", "resize", "--dimension=width", "--amount=10"]
"j" = ["flash", "tile", "resize", "--dimension=height", "--amount=10"]
"k" = ["flash", "tile", "resize", "--dimension=height", "--amount=-10"]
"<equal>" = ["flash", "tile", "balance"]
"<return>" = ["flash", "mode", "leave"]
```

Run one tiler: stop AeroSpace or yabai before turning `[tiling]` on.
